# 求职工作流

本次实现位于 `codex/feature-resume-workflow`，覆盖已选定的三轮改进。

## 功能入口

| 任务 | 入口与行为 |
| --- | --- |
| 创建与导入 | 工作台「新建简历」统一选择文件、粘贴、空白和分类示例；解析结果先对照原文校对，不直接写入。 |
| 编辑与预览 | 「写内容」「看版式 / 实时预览」切换；宽屏并排，小屏堆叠，工具面板使用抽屉。支持键盘排序。 |
| 内容检查与导出 | 「检查 / 导出」定位缺失项、查看实际分页；PDF、可编辑 DOCX、TXT、单份 JSON。过长条目阻止打印，提示先拆分。 |
| 岗位定制 | 「更多工具 → 为岗位创建版本」复制母版并关联公司、岗位和 JD；修改岗位版本不会影响母版。 |
| JD 证据 | JD 面板展示原文句子、必需/优先/待确认项、命中条目定位与学历/年限参考。重叠工作日期不重复累计。分数是本地规则参考，不是招聘系统通过率。 |
| 模块优化 | 「优化当前模块」选择条目及动作，逐条排队；每次外部调用均需确认，可停止剩余队列。量化事实由用户填写。 |
| 版本管理 | 「快照 / 比较 / 恢复」保留最近 20 份；投递关联快照长期保留。恢复前自动保存当前内容，并清理当前简历旧 AI 建议。 |
| 分类与语言 | AI 应用、前端、数据分析示例；应届/社招/转行场景；中英标准标题与日期。英文版式不自动翻译已有内容。 |
| 求职信 | 「更多工具 → 求职信」依据可见经历和技能生成本地草稿，编辑、保存及 TXT 下载。没有自动发送功能。 |
| 投递跟进 | 「记录投递」或侧栏「投递记录」关联准确简历快照，管理状态、日期、备注、搜索和跟进提示。 |
| 数据恢复 | 数据管理中先校验与预览，默认合并并重分配 ID；替换需显式选择。导出备份不包含密钥；未知服务不会自动启用。 |

## 验证记录

- TypeScript 检查、生产构建和 12 个文件中的 128 项单元测试通过。测试覆盖解析、事实保留、JD 匹配、备份校验、存储故障、模型传输、版本隔离/恢复、队列取消、分页以及 DOCX。
- DOCX 由独立的 Mammoth 解析器读回，验证文本、XML 特殊字符、语言标题及数字保留；浏览器中下载成功。
- 使用独立 localhost 测试来源的虚构资料，验证导入校对、实际预览、岗位版本、JD 证据、中英版式、快照比较/恢复、求职信、投递记录及到期跟进。
- 375px 手机与 1024px 平板宽度检查未出现整页横向溢出，宽屏编辑与预览并排。
- 完成代码差异审查，修复页面退出动画导致导航停留、日期输入未保存、离屏测量影响窄屏宽度以及异常模型地址残留队列的问题。

## 使用边界

数据仍存储在浏览器 localStorage，跨设备需手动备份/恢复。原文、图片和快照会增加占用，请关注保存状态。没有新增云端同步或自动投递。

PDF 使用浏览器系统打印，文件是否保存由系统对话框决定，快照标记为「导出准备」。本次未自动验证系统打印后的最终 PDF，也未连接真实外部模型。Word 导出为单栏文本布局，不包含头像，不保证与 PDF 相同分页。

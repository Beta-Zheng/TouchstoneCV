# 求职工作流

工作台覆盖导入、岗位定制、内容优化、导出与投递跟进。

## 功能入口

首次访问且没有本机使用记录时，显示「开始演示」「直接开始」。五步交互演示覆盖创建、编辑预览、岗位版本、固定投递快照和反馈记录；资料仅保存在弹窗内存中，不创建实际简历或投递记录。每步用短句与实际入口提示，自动演示关键操作，结果出现后停留；可暂停、重看、跳转或直接动手，输入会停止自动演示。动效包含按钮提示、卡片出现、预览同步、快照锁定及反馈统计变化，系统减少动态效果时关闭自动播放并使用即时展示。开始、退出或完成后记住选择，导航菜单的「使用指南」可重新打开。已有本机资料的用户自动跳过，清空简历不清除指南偏好；换浏览器或清除浏览器数据后可能再次询问。偏好存储被阻止时，本次页面会话内仍可记住选择。

使用指南验证：18 个测试文件共 178 项通过，类型检查、生产构建和差异检查通过。独立来源验证首次欢迎、开始/退出/完成后刷新不重复弹出、五步演示交互、练习不创建简历、手机菜单重新打开指南、Escape 退出及 375px 下无整页横向溢出。

| 任务 | 入口与行为 |
| --- | --- |
| 创建与导入 | 工作台「新建简历」统一选择文件、粘贴、空白和分类示例；解析结果先对照原文校对，不直接写入。 |
| 编辑与预览 | 「写内容」「内容与预览」「仅预览」切换；宽屏并排独立滚动，小屏切换内容与预览，工具面板使用抽屉。支持键盘排序。 |
| 内容检查与导出 | 「导出」定位缺失项、查看实际分页；PDF、可编辑 DOCX、TXT、单份 JSON。过长条目阻止打印，提示先拆分。 |
| 岗位定制 | 「求职流程 → 选择岗位」复制主简历并关联公司、岗位和 JD；修改岗位版本不会影响主简历。 |
| JD 证据 | JD 面板展示原文句子、必需/优先/待确认项、命中条目定位与学历/年限参考。重叠工作日期不重复累计。分数是本地规则参考，不是招聘系统通过率。 |
| 模块优化 | 「优化当前模块」选择条目及动作，逐条排队；每次外部调用均需确认，可停止剩余队列。量化事实由用户填写。 |
| 版本管理 | 「辅助工具 → 版本记录」支持只读查看、比较、恢复和变更摘要；保留初始、投递关联快照及最近 20 份其他快照。停止编辑 30 秒、离开编辑页或页面隐藏时记录有变化的版本。 |
| 分类与语言 | AI 应用、前端、数据分析示例；校招/实习/社招场景；中英标准标题与日期。英文版式不自动翻译已有内容。 |
| 求职信 | 「辅助工具 → 求职信」依据可见经历和技能生成本地草稿，编辑、保存及 TXT 下载。没有自动发送功能。 |
| 投递跟进 | 「记录投递」或侧栏「投递记录」固定关联实际投递快照，支持只读查看、状态图标、反馈时间线、跟进提示、状态分布及八周投递趋势。 |
| 数据恢复 | 数据管理中先校验与预览，默认合并并重分配 ID；替换需显式选择。导出备份不包含密钥；未知服务不会自动启用。 |

求职场景在创建页、编辑设置和备份校验中使用同一份定义。旧版转行场景在本机加载与备份恢复时归入社招，正文与快照内容保持原样。校招和实习示例使用学生身份、课程项目及教育时间，不沿用社招资深职位或企业成果；两类均检查教育经历。

主简历是内容来源，岗位简历是独立副本；来源更新仅提示，不自动覆盖。「对照并选择更新」展示差异，由用户勾选栏目整栏更新，保留岗位职位与未选内容，更新前后均保存快照。主简历和岗位简历均保留初始版本，普通编辑自动记录分组摘要，未逐次保存每个按键。旧简历首次编辑前保存原始内容，之前的修改历史未知。工作台使用可恢复归档，已有投递或衍生岗位版本的简历不能被普通删除操作清除。

实际投递后固定简历与快照，后续编辑当前简历不改变投递内容；再次使用不同版本投递应新增记录。待投递、未投递就撤回或岗位关闭不会自动伪造投递快照。投递状态与反馈手动填写；旧记录只展示已知状态，不推断早期反馈。统计按全部记录计算，趋势只使用填写的投递日期，面试与 Offer 比例按明确记录计算，无反馈不代表拒绝，也不会由 Offer 推断面试历史。

## 使用边界

数据存储在浏览器 IndexedDB，图片、原文与未修改条目通过内容引用共享；旧 localStorage 数据校验后迁移，跨设备需手动备份/恢复。原文、图片和快照会增加占用，请关注保存状态。没有新增云端同步或自动投递。

PDF 使用浏览器系统打印，文件是否保存由系统对话框决定，快照标记为「导出准备」。实际模板的三套中英双页 PDF 已通过独立文字、页数、尺寸与边界检查。系统打印对话框选项和真实外部模型仍需按使用环境验证。Word 导出为单栏文本布局，不包含头像，不保证与 PDF 相同分页。


## 本轮质量改进

- 五步求职流程直接显示在编辑器，辅助工具保留为次级入口。基础字段完成度与投递检查分开说明。
- 规则检查和模型写作分别标注；模型上下文包含可见经历和成果；未变动的建议不允许直接接受。模型支持英文条目翻译，标题/日期语言切换不冒充内容翻译。
- JD 证据优先，规则数值默认折叠；成果规则不把技术版本号算成指标，同一句中按分句区分必需和优先项。
- 求职信按 JD 词项排序真实证据，支持选取经历和填写应聘动机、岗位贡献；英文信含中文内容时提示先翻译。
- 品牌统一为 TouchstoneCV；示例电话使用明显占位值。
- 本机存储原子写入、共享资源去重、旧数据迁移、失败重试与陈旧窗口拒绝覆盖均有测试。迁移成功才移除旧副本，异常时原始数据不会被默认状态覆盖。
- `npm run test:exports` 生成 `.export-qa/` 中的 PDF、DOCX、页面 PNG 与报告。当前本机缺少 LibreOffice，Word 的真实渲染步骤尚未在本机执行；PR CI 设置 `REQUIRE_WORD_QA=1`，必须渲染 Word 后才通过。

本轮验证：14 个测试文件共 144 项通过，类型检查、生产构建及差异检查通过。真实 IndexedDB 测试覆盖事务、迁移、重新读取、旧窗口拒绝覆盖与孤立资源清理。三套模板各自的中英双页 PDF 共 12 页完成文字、尺寸、边界及页面图像检查；页面验证确认 375px 下无整页横向溢出、五步入口可用、规则无改动时禁用直接接受、保存完成后刷新可恢复版式语言。真实外部模型与远程 CI 本轮未运行。


## 编辑页布局改进

- 常驻工具收敛为文档操作与编辑视图两行；场景、语言、模板、外观和排版集中到「简历设置」。求职流程默认折叠。
- 「导出」保留主按钮，视图、步骤和缩放选中状态采用浅色或中性样式；移除排序编号、基本信息的零条计数和普通栏目的淡化。
- 经历卡片保留「优化这段」与「更多」；移动、显隐、删除进入菜单。格式工具在选择或聚焦时显示，成果操作在悬停/聚焦时显示，触屏保留可见操作。
- 使用目标职位、职位或角色、主要成果、补充信息等任务文字；详细说明改为按需展开。
- 宽屏支持正文与预览独立滚动，并可拖动分隔线或用方向键调整比例；小屏使用「写内容」「仅预览」两个视图。栏目目录中提供添加入口。
- 浏览器验证确认 1440px 下预览滚动独立，正文滚到教育经历后预览位置不变；375px 下无整页横向溢出，选择加粗、栏目入口和设置弹窗可用。
- 修复基本信息加粗标记直接出现在预览的问题，三套模板均加入回归测试；本轮 15 个测试文件共 147 项通过。

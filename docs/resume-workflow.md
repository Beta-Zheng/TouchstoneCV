# 求职工作流

工作台覆盖导入、岗位定制、内容优化、导出与投递跟进。

## 部署版体验改进（2026-10-25）

工作台默认列表，保留卡片切换；列表突出更新时间、待核对数量、导出准备及投递记录。显示「仅当前浏览器」与全量备份状态，备份入口不改动现有数据保管方式。首次欢迎以直接开始为主操作，演示仍可重看。

编辑器桌面目录和建议面板互斥，打开后占据独立列，不覆盖表单；窄屏继续使用抽屉。手机只保留文档栏、视图切换和「更多」，保存状态压缩到同一行，来源关系通过更多菜单查看。历史版本和针对岗位在桌面有直接入口。经历默认展开首条或新建空条目，其他经历展示摘要，点击预览或问题定位仍能展开目标条目。教育补充字段使用专业与学历文案。

基础检查只表示字段填写情况，示例电话和 example.com/org/net 邮箱提示核对。岗位内容通过明确确认保存手动快照；内容或 JD 变化后，旧确认不再视为当前确认；导出准备也按当前内容、模板、主题、语言和 JD 判断，不把旧导出当成当前导出。

JD 支持连续段落、同一行标题后的正文与无编号条目。无法提取的职责、要求、学历显示待核对，不宣称不存在要求。Milvus 等与向量数据库相关的工具单独作为可定位的待确认依据，不自动计入直接匹配分，也不认定用户能力缺失。原句依据默认折叠，建议与完整依据仍可查看。

导出默认包含姓名、公司、岗位和日期，可编辑文件名；PDF 为主操作，DOCX 为次操作，JSON/TXT 放入备份与文本格式。保留导出准备快照后可进入投递记录表单，但不会自动记录已投递或向企业发送简历。

投递列表支持快捷更新状态、追加反馈和跟进日期，保留已固定快照与完整时间线。待跟进筛选排除已结束记录，列表优先排列到期记录。累计已投递与当前状态分开显示；小于 10 条累计投递时只展示面试/Offer 记录分子与分母，不展示百分比。

共用弹窗通过可见标题关联可访问名称，手机导航暴露展开状态。缩略图原本已有 aria-hidden，不因 DOM 抓取中出现其文字而认定读屏缺陷。本轮浏览器回归不代替完整屏幕阅读器测试。

离屏试排在提交候选后等待布局及字体就绪再测量，避免连续试排读取上一轮尺寸；全内容已达标时不展示失败感的精简方案。`npm run test:usability` 验证列表切换、三种桌面宽度无侧栏遮挡、手机正文位置与弹窗、示例检查、确认失效、相关证据、导出文件名及投递、快照固定、快捷反馈、跟进筛选和篇幅成功提示。

## 编辑与预览点击定位

并排视图中，切换到另一条经历或栏目时定位对应预览；同一条目内切换字段、操作菜单、显隐与格式按钮不触发联动。用户手动浏览预览后，再点同一条目也不打断阅读，可使用工具栏「定位预览」主动返回。目标已经可见时不滚动，超出视口时只做必要的面板内滚动。跨页按条目 ID 定位；输入保持焦点，遵循减少动态效果偏好。

点击预览内容，或通过独立的「定位编辑」按钮使用 Enter/空格激活，可反向定位编辑卡片。保留预览的标题、段落及列表语义；定位按钮采用单一 Tab 入口，方向键和 Home/End 在各条目间移动。按钮在悬停或键盘聚焦时显示，缩放后保持实际点击尺寸。反向定位展开折叠条目并聚焦卡片容器，不自动进入输入框。宽屏保留并排视图，小屏返回「写内容」。隐藏或空内容给出提示，不自动显示；预览中的文本选择仍可用于复制。

定位使用约 1.2 秒的浅底色淡出，预览当前位置保留 2px 左侧标记；编辑区只强调标题行，不为整张卡片加框。减少动态效果时用静态浅底色，键盘操作按钮保留焦点框。重新分页后按 ID 恢复对应关系，不自动滚动。定位状态不写入简历，定位按钮和高亮不参与导出；没有连续滚动联动。

`npm run test:navigation` 在隔离浏览器验证跨页定位、短暂高亮、焦点保留、反向展开、鼠标及键盘激活、隐藏内容、手机视图和原始数据不变，已加入 PR CI。

## 智能篇幅调整（1 页 / 2 页）

导出弹窗「调整篇幅」进入同一调整流程，并关闭导出弹窗；不直接修改原稿。原先单向修改原稿的「切换紧凑布局」按钮已移除。

编辑工具栏「篇幅调整」和「简历设置 → 排版 → 智能调整为 1 / 2 页」提供同一入口。目标是页数上限，不强制补空白页；原稿实测一页时默认一页，其余默认两页。原稿已满足上限时保持原排版，「完成」关闭弹窗，不生成重复副本。否则比较适中/紧凑间距、横排标题和字号候选，优先少缩字、少改间距，结合第二页利用率排序；正常字号不降到 14px 以下（用户原本更小的字号不再缩小）。预览和方案搜索共用实际 DOM 测量与分页逻辑，并等待字体和图片就绪。

排版仍超页时，可选择「保留全部内容」或「精简部分内容」。默认锁定最近工作、教育以及学生的相关项目；近期判断包含在职状态和结束日期，用户可以主动解锁或锁定其他条目。自动建议结合 JD 词项和实测高度，按内容损失与空间收益取舍，并尝试恢复仍装得下的条目；这是本地启发式，不保证全局最优。用户可按栏目调整纳入条目、查看原文，锁定条目不能被取消。隐藏全部工作或教育时给出提示。

摘要展示字号、间距、标题布局和隐藏数量差异，支持切换原稿对照。测量中、预览更新中、失败及未达标分开反馈，失败可重试；第二页过少时提示尝试一页，不强制填满。建议不改写描述、技能或数字，仅在新副本中隐藏选定条目；原简历、JD、岗位关联和已有投递快照不变，新副本保存初始及调整后快照。没有自动模型调用。单个条目过长时列出具体条目，提供「前往编辑」定位入口；自动跨页拆分长条目尚未实现，继续禁止超长或未完成测量方案创建。

紧凑设置原先被部分正文的固定宽松行高覆盖，现已改为使用密度对应行高。设置明确为「纸张密度」，作用于预览和导出，而不是编辑表单大小。

## 页面视觉与文案

平台控件优先采用本地打包的 Noto Sans SC 无衬线字体，并提供系统字体回退；页面标题 28px、弹窗标题 20px、正文与常规按钮 14px、辅助文字至少 12px。文档模板仍使用各自的字体设置。共享图标使用项目已有 Lucide 线性图标（1.75px 描边），导航 20px、按钮 18px，工作台与投递入口分别使用仪表盘与发送图标。

按钮提供常规 40px、紧凑 32px、大号 44px 三种尺寸；触屏的共享按钮、图标按钮及编辑视图控件至少 44px。主操作使用品牌色，次级操作使用描边或文本，危险操作保留红色。键盘焦点使用清晰轮廓，禁用状态保留不可用鼠标指针。手机顶栏为 64px，正文同步偏移，避免导航遮挡编辑标题。

业务下拉框统一使用 8px 圆角、14px 文字和线性箭头，保留原生选择与手机系统选项面板；编辑工具下拉使用紧凑尺寸。操作菜单共用边框、阴影、选中及禁用样式，默认菜单项至少 36px，触屏为 44px。支持方向键打开与移动、Home/End、Escape 返回触发按钮、Tab 关闭及点击外部关闭；空间不足时向上展开并限制高度滚动。开关的可点击区域与可见轨道分离，触屏点击区域至少 44px，状态仍以 aria-checked 表达。系统原生选项面板的具体外观由浏览器及操作系统决定。

界面标题与正文统一使用无衬线字体，简历模板仍按各自字体设置输出。操作按钮使用高对比度纯色，普通按钮取消发光、浮起和缩放。工作台用真实内容缩略图展示简历，统计收为一行，填写情况与版本信息按需展开；缩略图对辅助技术隐藏，避免重复朗读，并对未改变的简历复用渲染。

投递页优先展示记录，状态分布与趋势由「查看投递统计」展开。模型参数、连接帮助、存储与隐私细节、版本保存规则和打印说明按需查看；恢复合并/替换、外部发送确认、清空数据及 Word/PDF 格式差异的关键提示保留。模板说明仅描述实际布局，不承诺招聘筛选结果。开关圆点定位修正为关闭靠左、开启靠右。

本轮验证：178 项测试、类型检查和生产构建通过；三套模板的中英双页 PDF 六组通过文字、页数、尺寸和边界检查。本机未执行 Word 的实际渲染。独立来源验证缩略图、搜索筛选、中文模型策略、开关状态、统计展开，以及 375px 下工作台、投递页和简历预览无整页横向溢出。

## 功能入口

首次访问且没有本机使用记录时，显示「开始演示」「直接开始」。五步交互演示覆盖创建、编辑预览、岗位版本、固定投递快照和反馈记录；资料仅保存在弹窗内存中，不创建实际简历或投递记录。每步用短句与实际入口提示，自动演示关键操作，结果出现后停留；可暂停、重看、跳转或直接动手，输入会停止自动演示。动效包含按钮提示、卡片出现、预览同步、快照锁定及反馈统计变化，系统减少动态效果时关闭自动播放并使用即时展示。开始、退出或完成后记住选择，导航菜单的「使用指南」可重新打开。已有本机资料的用户自动跳过，清空简历不清除指南偏好；换浏览器或清除浏览器数据后可能再次询问。偏好存储被阻止时，本次页面会话内仍可记住选择。

使用指南验证：18 个测试文件共 178 项通过，类型检查、生产构建和差异检查通过。独立来源验证首次欢迎、开始/退出/完成后刷新不重复弹出、五步演示交互、练习不创建简历、手机菜单重新打开指南、Escape 退出及 375px 下无整页横向溢出。

求职场景在创建页、编辑设置和备份校验中使用同一份定义。旧版转行场景在本机加载与备份恢复时归入社招，正文与快照内容保持原样。校招和实习示例使用学生身份、课程项目及教育时间，不沿用社招资深职位或企业成果；两类均检查教育经历。

主简历是内容来源，岗位简历是独立副本；来源更新仅提示，不自动覆盖。「对照并选择更新」展示差异，由用户勾选栏目整栏更新，保留岗位职位与未选内容，更新前后均保存快照。主简历和岗位简历均保留初始版本，普通编辑自动记录分组摘要，未逐次保存每个按键。旧简历首次编辑前保存原始内容，之前的修改历史未知。工作台使用可恢复归档，已有投递或衍生岗位版本的简历不能被普通删除操作清除。

实际投递后固定简历与快照，后续编辑当前简历不改变投递内容；再次使用不同版本投递应新增记录。待投递、未投递就撤回或岗位关闭不会自动伪造投递快照。投递状态与反馈手动填写；旧记录只展示已知状态，不推断早期反馈。统计按全部记录计算，趋势只使用填写的投递日期，面试与 Offer 比例按明确记录计算，无反馈不代表拒绝，也不会由 Offer 推断面试历史。

## 使用边界

数据存储在浏览器 IndexedDB，图片、原文与未修改条目通过内容引用共享；旧 localStorage 数据校验后迁移，跨设备需手动备份/恢复。原文、图片和快照会增加占用，请关注保存状态。没有新增云端同步或自动投递。

PDF 使用浏览器系统打印，文件是否保存由系统对话框决定，快照标记为「导出准备」。实际模板的三套中英双页 PDF 已通过独立文字、页数、尺寸与边界检查。系统打印对话框选项和真实外部模型仍需按使用环境验证。Word 导出为单栏文本布局，不包含头像，不保证与 PDF 相同分页。


## 本轮质量改进
